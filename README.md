# 3D Portfolio Awards

A modern, interactive 3D portfolio website showcasing projects and awards with cutting-edge web technologies. This project combines React, Three.js, and advanced animations to create an immersive user experience.

## ✨ Features

- **Interactive 3D Graphics**: Powered by Three.js and React Three Fiber for stunning visual effects
- **Smooth Animations**: GSAP-powered animations for fluid transitions and interactions
- **Responsive Design**: Mobile-first approach using Tailwind CSS for all screen sizes
- **Smooth Scrolling**: Lenis integration for butter-smooth scroll experiences
- **AI Integration**: Google GenAI integration for dynamic content generation
- **Performance Optimized**: Built with Vite for fast development and production builds
- **Modern UI/UX**: Clean, professional interface with interactive components

## 🛠️ Tech Stack

- **Frontend Framework**: React 19.2.0
- **Build Tool**: Vite 7.2.4
- **3D Graphics**: Three.js 0.181.2
- **3D React Integration**: React Three Fiber 9.4.2
- **Animations**: GSAP 3.13.0 with React support
- **Styling**: Tailwind CSS 4.1.17
- **Smooth Scroll**: Lenis 1.3.15
- **AI Integration**: Google GenAI SDK 1.46.0
- **Language**: JavaScript (93.4%) | CSS (5.9%) | HTML (0.7%)

## 📦 Installation

### Prerequisites
- Node.js 16.0 or higher
- npm or yarn package manager

### Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/ab9898998989898/3D-Portfolio-Awards.git
   cd 3D-Portfolio-Awards
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```
   The application will be available at `http://localhost:5173`

## 🚀 Usage

### Development

- **Start Dev Server**: `npm run dev` - Runs Vite with HMR (Hot Module Replacement)

## 🎨 Key Technologies Explained

### Three.js & React Three Fiber
Used for rendering 3D scenes and objects. React Three Fiber provides a React component-based API for Three.js.

### GSAP (GreenSock Animation Platform)
Industry-standard animation library used for smooth, performant animations and transitions throughout the application.

### Tailwind CSS
Utility-first CSS framework for rapid UI development with a consistent design system.

### Lenis
Smooth scroll library that enhances the scrolling experience with physics-based smoothing.

## 📱 Responsive Design

The project is fully responsive and optimized for:
- Desktop (1920px and above)
- Tablet (768px - 1919px)
- Mobile (< 768px)

Uses `react-responsive` for breakpoint detection and dynamic component rendering.
